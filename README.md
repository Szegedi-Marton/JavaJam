# 🎵 JavaJam

### Good music is better together.

JavaJam is a Java desktop music player that combines YouTube playback with shared listening sessions. Discover music, play your favorite tracks, and listen alongside your friends.

## ✨ Features

- 🎧 YouTube music playback
- 🔎 Search and discover tracks
- ⏯️ Play, pause, stop and skip controls
- ⏩ Playback progress and seek bar
- 🔀 Shuffle mode
- 🔁 Repeat mode
- 🔊 Volume control
- 👥 Listen-together sessions
- 🌐 Shared playback synchronization
- 🌙 Dark-themed interface

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Java | Core application |
| Java Swing | Desktop interface |
| JCEF | Embedded Chromium browser |
| YouTube IFrame API | Video playback |
| Maven | Dependency management |
| Java Networking | Shared listening sessions |

## 🚀 Getting Started

### Requirements

- Java JDK 17+
- Maven
- Internet connection
- Operating system supported by JCEF

### Installation

**1. Clone the repository**

    git clone https://github.com/szmartin16/JavaJam.git

**2. Navigate to the project**

    cd JavaJam

**3. Build the application**

    mvn clean install

**4. Run the application**

Run through your IDE or configured Maven entry point.

## 🎶 Listen Together

JavaJam lets you share your listening experience with friends.

### Hosting a Session

1. Launch JavaJam.
2. Click the **Jam** button.
3. Select **Host Session**.
4. Enter a port number.
5. Share your IP address and port with friends.

⚠️ For public network RadminVPN or Hamachi are recommended ⚠️

### Joining a Session

1. Launch JavaJam.
2. Click the **Jam** button.
3. Select **Join Session**.
4. Enter the host's IP address and port.
5. Connect and enjoy the music together!
